# 📊 Online Retail Sales Analysis

## 📌 Project Overview

This project analyzes an Online Retail dataset to identify sales trends, customer behavior, product performance, and revenue patterns.

The project combines **Python for data cleaning and exploratory data analysis (EDA)** with **Power BI for interactive business dashboarding**.

## 🎯 Objectives

* Analyze overall sales and revenue performance
* Identify monthly sales trends
* Analyze product performance
* Identify top-performing countries
* Analyze customer segments and customer value
* Understand sales vs. returns
* Build an interactive Power BI dashboard
* Generate business insights from retail data

## 🔍 Python Analysis

The dataset was cleaned and analyzed using Python.

Key steps included:

* Data cleaning

* Creating revenue-related columns
* Identifying sales and returns
* Exploratory Data Analysis
* Product and country-level analysis

## 📊 Power BI Dashboard

An interactive Power BI dashboard was created to provide a clear view of retail performance.

### Key KPIs

* **Net Revenue**
* **Total Orders**
* **Total Customers**
* **Average Order Value (AOV)**

### Dashboard Analysis

* Monthly Revenue Trend
* Top Countries by Revenue
* Top Products by Revenue
* Sales vs Returns
* Customer Segmentation
* Interactive Slicers and Filters

## 💡 Key Business Insights

* The **United Kingdom** generated the highest revenue.
* Revenue showed noticeable variation across different months.
* A small group of products contributed significantly to overall revenue.
* Customer segmentation helped identify high-value customers.
* Returns had a measurable impact on net revenue.
* The dashboard provides an easy way to monitor sales performance and customer behavior.
